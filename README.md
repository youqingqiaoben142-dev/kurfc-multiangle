# KURFC マルチアングル

鹿児島大学ラグビー部（KURFC）の試合動画を、最大4アングルまで同期して並べて見るためのビューアです。

**使う：** https://youqingqiaoben142-dev.github.io/kurfc-multiangle/

- 各枠に「PCやスマホの動画ファイル」か「YouTubeのURL」を入れる
- `1`〜`4` でメインのアングルを切り替え、`G` で 2×2 表示
- 「同期を合わせる」で各カメラの録画開始のズレを揃える
- トライ・スクラムなどのタグを付けて、一覧から頭出し

動画はどこにもアップロードされません（ファイルはその端末の中で再生、YouTubeは埋め込みで再生）。
同期のズレやタグは、使っているブラウザの中にだけ保存されます。
